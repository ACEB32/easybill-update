# EasyBill update notice

This file is the only thing an office copy of EasyBill reads. It does not contain customer data.

Edit easybill-version.json and raise version above the copy a utility is running. Their Desk then says an update is ready. After they install the new copy, set the version in that copy to the same number so the notice goes away.

The billing program calls out to this file. Nothing connects in to the billing PC.
